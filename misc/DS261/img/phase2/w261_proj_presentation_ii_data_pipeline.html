🛫Flight Delay Prediction Data Pipeline

🔍
Data Mining
▼
  • Generating statistics:
    • Count, min, max, mean, median, stddev for numeric columns
    • Distinct count, top 10 samples, null count, null percentage
  • Narrow down features based on data dictionary and statistics with decision reasons
  • Define column types and conversions:
    • Numeric, Categorical, Datetime
    • String to numeric (HourlyVisibility, ...)
    • Numeric to String (OP_CARRIER_FL_NUM, ...)
↓
✨
Feature Engineering
▼
  • Remove records with null DEP_DEL15 targets (canceled flights)
  • Data type conversions as defined in data mining step
  • Find previous flight info grouped by tail number only for OTPW:
    • Previous DEP_DELAY instead of ARR_DELAY to avoid data leakage
    • Previous DEP_DELAY_GROUP
    • Previous DIVERTED
  • Engineer additional features:
    • IS_HOLIDAY based on holiday dataset and FL_DATE
    • Optional: airport PageRank
    • Optional: weather severity index
↓
🩹
Data Imputation
▼
  • Impute categorical features with 'Unknown' category (i.e., TAIL_NUM)
  • Impute weather features using min statistics (i.e., HourlyWindDirection)
  • Impute weather features using median statistics (i.e., HourlyVisibility)
  • Ensure null percentage is 0% for all features after imputation
↓
⚖️
Class Rebalancing
▼
  • Training dataset ONLY
  • Calculate class counts for each month
  • Add a random number for sampling within each month-class group
  • Balances classes within each month by undersampling the majority class
↓
